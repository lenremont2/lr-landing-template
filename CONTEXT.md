# LR Landing Build System

Система подготовки лендингов Lenremont из исходников Astro к публикации через плагин HTML On Page.

## Language

**Landing Kit**:
Единый версионируемый npm-пакет, который создаёт Astro-проект и сопровождает его подготовку к публикации в Lenremont на всём жизненном цикле.
_Avoid_: генератор лендинга, пакет create-landing, шаблон WordPress

**Модуль WP-экспорта**:
Детерминированная часть Landing Kit, преобразующая Astro-сборку в WP-фрагмент и медиапакет по правилам Lenremont.
_Avoid_: отдельный npm-пакет, WP-сборщик внутри лендинга, скрипт конвертации проекта

**WP-фрагмент**:
Один HTML-файл без документных обёрток, предназначенный для вставки в плагин HTML On Page.
_Avoid_: WordPress-страница, WordPress-шаблон, готовый сайт

**Медиапакет**:
Набор оптимизированных медиафайлов WP-фрагмента, предназначенный для отдельной загрузки в медиатеку WordPress.
_Avoid_: статические файлы сборки, WP assets

**Медиа-публикация**:
Автоматическая загрузка медиапакета в медиатеку WordPress с получением фактического URL каждого файла до публикации WP-фрагмента.
_Avoid_: ручная загрузка assets, предположение о маршруте uploads

**Неизменяемое медиа**:
Медиафайл с именем, зависящим от содержимого, который после загрузки не перезаписывается и может безопасно использоваться опубликованными версиями.
_Avoid_: замена файла по прежнему URL, изменяемый asset

**API публикации**:
Защищённый API плагина HTML On Page для загрузки медиа и записи WP-фрагмента с использованием общего `X-HtmlOnPage-Token`.
_Avoid_: WordPress Application Password, встраивание PHP-плагина в Landing Kit

**План публикации**:
Неизменяемое описание целевой страницы, проверенного WP-фрагмента, медиа и ожидаемых изменений, которое пользователь подтверждает до записи в WordPress.
_Avoid_: предварительный просмотр, автоматическое разрешение, команда без цели

**Паспорт публикации**:
Версионируемый файл `landing.config.json` с безопасной идентификацией проекта и целевой страницы, а также точечными исключениями валидации.
_Avoid_: конфигурация дизайна, хранилище контента, файл секретов

**Исключение валидации**:
Зафиксированное разрешение на одно конкретное отклонение от правила с точным условием и обязательным обоснованием.
_Avoid_: force, отключение валидатора, игнорирование ошибок

**Целевая страница**:
Заранее созданная страница WordPress, идентифицированная `PAGE_ID` и предназначенная для получения проверенного WP-фрагмента.
_Avoid_: автоматически созданная страница, новый лендинг в WordPress
