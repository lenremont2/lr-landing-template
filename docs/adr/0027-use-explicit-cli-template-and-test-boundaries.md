# Разделить CLI, статический шаблон и проверки пакета

Репозиторий Landing Kit разделяется на четыре явные области: исполняемая точка входа в `bin`, CLI и его прикладная логика в `src`, непосредственно копируемый проект в `templates/base`, а также автоматические проверки в `test` и `scripts`.

Шаблон не импортирует исходный код генератора и может читаться как самостоятельный Astro-проект. CLI не содержит файлов лендинга строковыми литералами, а тесты обращаются к публичной команде и упакованному npm-артефакту.

В публикуемый пакет по явному whitelist входят `bin`, `src`, `templates`, `README.md` и `LICENSE`. Документация проектирования, тесты и релизные сценарии остаются в исходном репозитории.
