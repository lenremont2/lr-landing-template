# Использовать модульный SCSS с одной точкой входа

Стили лендинга будут разделены на SCSS partial-файлы для core, UI и секций и собираться через единый `src/styles/landing.scss`; component-scoped `<style>` в Astro-компонентах запрещён. Это сохраняет явное начало каждого собственного селектора с `#hop-landing`, исключает скрытую зависимость от `data-astro-*` и упрощает будущую проверку и встраивание CSS в WP-фрагмент.
