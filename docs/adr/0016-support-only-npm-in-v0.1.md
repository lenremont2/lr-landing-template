# Поддерживать только npm в версии 0.1

Первая версия `@lenremont2/landing-kit` использует единственный менеджер пакетов — npm. Создание проекта выполняется через `npx`, зависимости устанавливаются командой `npm install`, а их точное дерево фиксируется в `package-lock.json`.

Автоматическое определение и отдельная поддержка pnpm, Yarn и Bun в версию 0.1 не входят. Это сохраняет один воспроизводимый путь установки и сокращает поверхность тестирования генератора. Поддержку других менеджеров пакетов можно добавить позднее без изменения архитектуры создаваемого Astro-проекта.

Astro, Sass, Landing Kit и инструменты контроля качества являются зависимостями разработки и размещаются в `devDependencies`: итоговый статический HTML не требует Node.js-зависимостей во время выполнения.

При создании проекта без установки зависимостей генератор записывает `package.json`, но не создает искусственный lock-файл. `package-lock.json` появляется после первого `npm install`.
