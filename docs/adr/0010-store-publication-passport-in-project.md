# Хранить паспорт публикации в проекте

Каждый проект будет содержать версионируемый `landing.config.json`, проверяемый по JSON Schema из Landing Kit и хранящий идентификатор проекта, сайт, `PAGE_ID` и точечные исключения валидации. Контент, визуальные параметры, путь uploads и секреты в паспорт не входят; пустой `PAGE_ID` создаётся генератором и заполняется скиллом после подтверждения при первой публикации.
