# Включать краткие правила агента и полный справочник разработки

Генератор будет копировать в каждый проект короткий обязательный `AGENTS.md` с командами и критическими ограничениями, а также полный snapshot мастер-промпта в `docs/MASTER_DEVELOPMENT_PROMPT.md`; оба документа отмечаются версией Landing Kit. Размещение всей инструкции в `AGENTS.md` отклонено из-за постоянной нагрузки на контекст, а автоматическая синхронизация правил в существующие проекты запрещена во избежание скрытых изменений контракта.
