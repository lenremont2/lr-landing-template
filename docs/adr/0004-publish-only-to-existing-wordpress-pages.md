# Публиковать только в существующие страницы WordPress

Landing Kit и управляющий Codex-скилл будут вставлять или заменять WP-фрагмент только в заранее созданной целевой странице по явному `PAGE_ID`. Создание страниц, назначение slug, выбор шаблона и управление статусом остаются в WordPress; расширение плагина API создания страниц отклонено как лишнее расширение ответственности и риска публикации.
