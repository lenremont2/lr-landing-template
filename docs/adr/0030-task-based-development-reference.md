# Доставлять технический справочник по главам

Для работы над формой, стилями или встраиванием нужны разные части технического контракта. В `docs/MASTER_DEVELOPMENT_PROMPT.md` хранится оглавление. Старые якоря указывают на строку соответствующей главы. В новых маршрутах и скиллах ссылки ведут сразу к инструкции в `docs/landing-kit/`.

Решение уточняет [состав справочника](0014-bundle-compact-agent-rules-and-full-development-reference.md) и [границы обновления](0029-create-in-current-directory-and-update-managed-infrastructure.md). Команда `create` копирует справочник вместе с шаблоном. Команда `update` устанавливает оглавление и главы, поставляемые комплектом. Главы содержат метку владельца. При совпадении имени с локальным файлом без метки обновление останавливается до записи. Остальные файлы в каталоге принадлежат проекту.
