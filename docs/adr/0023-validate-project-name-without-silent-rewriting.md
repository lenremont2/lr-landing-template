# Проверять имя проекта без скрытого преобразования

Имя создаваемого проекта должно быть совместимо с названием каталога, командной строкой и полем `name` в `package.json`. Разрешены строчные латинские буквы, цифры и дефисы; первый и последний символ должны быть буквой или цифрой.

Пробелы, кириллица, символы подчеркивания, прописные буквы и специальные символы не принимаются. Генератор не изменяет введенное имя молча: он прекращает создание проекта, объясняет правило и выводит нормализованный вариант только как предложение для повторного запуска.

То же проверенное имя используется для каталога и npm-имени проекта. В создаваемом `package.json` устанавливается `"private": true`, чтобы исключить случайную публикацию отдельного лендинга в npm.
