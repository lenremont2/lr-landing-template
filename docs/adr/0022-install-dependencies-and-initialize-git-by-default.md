# По умолчанию устанавливать зависимости и инициализировать Git

Вызов `npx @lenremont2/landing-kit create <project-name>` работает без дополнительных вопросов, устанавливает зависимости командой `npm install` и инициализирует Git-репозиторий.

Если целевой каталог находится внутри уже существующего Git worktree, генератор не создает вложенный репозиторий и явно сообщает о пропуске `git init`. Пользователь может отключить стандартные действия флагами `--no-install` и `--no-git`.

При вызове `create` без имени проекта используется согласованный интерактивный режим: генератор запрашивает название проекта, необходимость установки зависимостей и необходимость инициализации Git.
