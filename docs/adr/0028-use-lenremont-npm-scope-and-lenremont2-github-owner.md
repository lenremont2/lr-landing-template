# Использовать npm-scope lenremont и GitHub-владельца lenremont2

Публичный npm-пакет публикуется как `@lenremont/landing-kit`, потому что фактическое имя npm-пользователя — `lenremont`. Исходный GitHub-репозиторий размещается как `lenremont2/lr-landing-template`, потому что соответствующее имя GitHub-пользователя — `lenremont2`.

Эти идентификаторы принадлежат одному владельцу, но npm и GitHub рассматривают их независимо. Не существующий npm-scope `@lenremont2` не используется и не подменяется предположением о соответствии имён между сервисами.
