# Загружать медиа через API HTML On Page

Плагин HTML On Page будет расширен защищённым маршрутом загрузки медиа, использующим существующий `X-HtmlOnPage-Token`; Landing Kit будет обращаться только к этому API-контракту. Стандартный `/wp/v2/media` с WordPress Application Password отклонён из-за более широких полномочий, а PHP-код плагина не будет включаться в npm-пакет или проекты лендингов.
