# Использовать отдельный версионируемый модуль WP-экспорта

Логика преобразования Astro-сборки в WP-фрагмент и медиапакет будет жить в отдельном общем модуле, а каждый проект лендинга будет явно фиксировать его версию. Это позволяет исправлять правила конвертации централизованно, не изменяя существующие проекты самопроизвольно; копирование сборщика в каждый репозиторий и хранение актуальной логики только в стартовом каркасе отклонены из-за неизбежного расхождения версий.
