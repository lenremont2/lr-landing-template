# Рекомендовать Node 24 и поддерживать Node 22.12+

Основной средой разработки Landing Kit и создаваемых проектов является LTS-ветка Node 24. В шаблон добавляется `.nvmrc` с версией `24`.

Поле `engines.node` допускает поддерживаемые Astro четные ветки Node 22 и Node 24: `^22.12.0 || ^24.0.0`. Команда Landing Kit проверяет текущую версию Node до создания проекта и прекращает работу на версии ниже 22.12.0 или на неподдерживаемой ветке.

Node 22 сохраняется для совместимости, но новая разработка и проверка релиза ориентируются прежде всего на Node 24. Поддержка следующих веток добавляется отдельным обновлением Landing Kit после проверки совместимости всего набора зависимостей.
