# Не создавать проект в непустом каталоге

Команда `create` создает отсутствующий целевой каталог или использует существующий пустой каталог. Если в целевом каталоге уже находится хотя бы один файл или подкаталог, генератор прекращает работу до любых изменений.

Версия 0.1 не предоставляет флаг `--force` и не удаляет существующее содержимое. Сообщение об ошибке показывает разрешенный абсолютный путь и предлагает выбрать другое имя проекта либо самостоятельно подготовить пустой каталог.

Это правило защищает существующие проекты и пользовательские файлы от случайной перезаписи, а также сохраняет однозначное поведение команды в интерактивном и неинтерактивном режимах.
