# Поставлять шаблон проекта внутри npm-пакета

Стартовый Astro-шаблон хранится и публикуется внутри `@lenremont/landing-kit`. Команда `create` не клонирует отдельный GitHub-репозиторий и не скачивает шаблон из внешнего источника.

Версия структуры, правил, конфигурации, диагностического экрана и инструментов проекта тем самым однозначно связана с версией npm-пакета. Создание проекта зависит только от получения Landing Kit из npm, а конкретную старую структуру можно воспроизвести запуском закрепленной версии пакета.

GitHub-репозиторий является местом разработки исходного кода Landing Kit. npm-пакет является распространяемым самодостаточным продуктом и содержит только файлы, необходимые для генерации и последующего сопровождения лендинга.
