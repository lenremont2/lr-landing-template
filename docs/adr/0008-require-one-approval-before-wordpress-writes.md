# Требовать одно подтверждение перед изменениями WordPress

Скилл выполняет локальную сборку, валидацию и удалённые операции чтения без подтверждения, затем показывает неизменяемый план публикации и запрашивает одно явное разрешение на загрузку медиа и замену HTML. Разрешение применяется только к показанным артефактам и целевой странице; изменение их состава аннулирует его и требует нового подтверждения.
