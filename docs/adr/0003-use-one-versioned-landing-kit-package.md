# Использовать один версионируемый пакет Landing Kit

Создание Astro-проекта и повторяемые операции WP-экспорта будут предоставляться одним публичным пакетом `@lenremont2/landing-kit`: команда создания добавляет в новый проект точную версию этого же пакета, а проект использует её для сборки, проверки и публикации. Разделение на `create-landing` и `wp-export` отменено, поскольку все создаваемые проекты всегда используют единый WP-процесс, а независимые жизненные циклы пакетов пока не оправдывают дополнительную сложность.
