# Автоматически загружать медиа до публикации HTML

Управляемая из чата публикация будет автоматически загружать весь медиапакет в WordPress, получать фактические URL и только затем формировать и публиковать окончательный WP-фрагмент. Ручная загрузка медиа и предварительное угадывание каталога `/uploads/ГГГГ/ММ/` отклонены: при неполной загрузке или несовпадении URL публикация HTML должна останавливаться.
