# Закреплять Landing Kit в создаваемых проектах

Каждый проект, созданный командой `npx @lenremont/landing-kit create`, сохраняет `@lenremont/landing-kit` в `devDependencies` с точной версией без диапазонов `^` и `~`.

Первоначальный вызов через `npx` запускает генератор, а локально установленная зависимость сопровождает проект после создания. Благодаря этому последующие команды проверки, сборки и будущего WP-экспорта могут вызываться через `npm scripts` и используют версию Landing Kit, с которой совместим конкретный проект.

Landing Kit не обновляется автоматически. Переход проекта на новую версию выполняется явно, чтобы обновление правил или сборочной логики не меняло существующие лендинги без решения разработчика.
