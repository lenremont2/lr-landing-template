# Использовать неизменяемые медиа с хешем содержимого

Имена публикуемых медиа будут включать хеш содержимого; API переиспользует уже загруженный идентичный файл, но никогда не перезаписывает существующее вложение изменёнными данными. Это сохраняет работоспособность старых и откатываемых WP-фрагментов и исключает ошибки кеширования ценой накопления файлов, очистка которых выполняется отдельным процессом.
