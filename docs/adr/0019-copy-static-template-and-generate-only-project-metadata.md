# Копировать статический шаблон и генерировать только метаданные проекта

Landing Kit хранит готовое дерево проекта в `templates/base` и при выполнении команды `create` копирует его в целевой каталог без программной сборки содержимого каждого файла.

Динамически создаются только данные, действительно зависящие от нового проекта: прежде всего `package.json` с именем проекта, точными версиями зависимостей и версией `@lenremont2/landing-kit`. Для стартового шаблона не вводятся отдельный шаблонизатор, универсальная система токенов или условная генерация файлов.

После копирования команда при необходимости запускает `npm install` и `git init`. Такой подход делает шаблон непосредственно читаемым и тестируемым в репозитории, а генератор оставляет небольшим и предсказуемым.
