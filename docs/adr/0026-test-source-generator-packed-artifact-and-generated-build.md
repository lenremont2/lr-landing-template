# Проверять исходный CLI, npm-архив и сборку созданного проекта

Landing Kit использует три уровня автоматической проверки.

Быстрые тесты на `node:test` проверяют чистую логику: имена и аргументы, требования к Node.js, состояние целевого каталога и обнаружение родительского Git-репозитория.

Интеграционный тест запускает команду `create` во временном каталоге с флагами `--no-install --no-git`, после чего проверяет сформированное дерево, `package.json`, обязательные файлы, точные версии и отсутствие непредусмотренного содержимого.

Релизный smoke-тест сначала выполняет `npm pack`, затем запускает упакованный артефакт, создает новый лендинг, устанавливает его зависимости, выполняет `npm run quality` и проверяет результат в `dist`. Таким образом тестируется именно содержимое будущей npm-публикации, а не только рабочая копия репозитория.

Полные снимки всех файлов не являются основным контрактом тестов: проверяются ожидаемый манифест дерева и содержательные инварианты, чтобы безопасные изменения текста не создавали лишний шум.
