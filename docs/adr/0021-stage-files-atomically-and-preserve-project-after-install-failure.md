# Подготавливать файлы атомарно и сохранять проект при ошибке установки

Перед записью в целевой каталог команда `create` формирует проект во временном каталоге рядом с целевым и проверяет полноту подготовленного дерева. Неуспешная подготовка удаляет только временные данные и не оставляет частично созданный проект.

После успешной подготовки файлы переносятся в целевой каталог, затем запускается `npm install`, а инициализация Git выполняется последней. Если установка зависимостей завершается ошибкой, исходные файлы проекта сохраняются, команда возвращает ненулевой код и сообщает, что установку можно повторить вручную командой `npm install`.

Сетевая или реестровая ошибка npm не является основанием удалять корректно сформированный проект. При этом сбой до завершения формирования файлов не должен оставлять неполное дерево в целевом каталоге.
