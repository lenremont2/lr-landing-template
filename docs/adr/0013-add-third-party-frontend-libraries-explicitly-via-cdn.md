# Подключать frontend-библиотеки явно через CDN

Стартовый проект не включает Swiper, GLightbox, GSAP, AOS, Font Awesome или другие runtime-библиотеки; используемая библиотека добавляется напрямую в `LandingLayout.astro` через CDN с точной версией и не устанавливается через npm. Универсальный loader и конфигурационные флаги отклонены как скрытая сложность, а явные теги позволяют сразу видеть внешние зависимости и сохранять их при будущем WP-экспорте.
