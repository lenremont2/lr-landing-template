# Запретить общий обход валидации

Критические ошибки блокируют публикацию и не могут быть обойдены флагом `--force`; допустимо только точечное исключение для конкретного правила и совпадения с обязательной причиной, после чего выполняется полная повторная проверка. Предупреждения остаются видимыми в плане публикации и принимаются общим подтверждением пользователя.
