# Использовать один entrypoint для vanilla JavaScript

Интерактивная логика будет разделена на создаваемые по необходимости модули в `src/scripts`, но подключаться к странице только через `landing.js`, который находит `#hop-landing`, защищается от повторной инициализации и передаёт корень компонентам. Скрипты внутри Astro-компонентов, глобальные переменные и framework hydration отклонены как скрытые зависимости, усложняющие проверку и будущую сборку одного WP-скрипта.
