# Разделить генератор проекта и рабочий WP-инструмент

Новые Astro-проекты будут создаваться одноразовым npm-пакетом `@lenremont2/create-landing`, а повторяемые операции сборки и подготовки результата будет выполнять отдельный версионируемый пакет, закреплённый в каждом проекте. Разделение позволяет независимо развивать стартовый каркас и правила обработки существующих лендингов; объединение этих жизненных циклов в одном пакете отклонено.
