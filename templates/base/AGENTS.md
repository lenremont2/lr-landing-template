# Правила лендинга Lenremont

Rules snapshot: @lenremont/landing-kit 0.4.0.

[Дерево проекта](README.md) показывает, где вести [бриф](docs/product/brief.md), [задачи](docs/tasks/task-template.md) и [архитектурные решения](docs/decisions/README.md).

Выбери работу по [карте маршрутов](.agents/workflows/landing.md) и прочитай скилл текущего шага. Перед существенной правкой сформулируй проверяемый результат. В [техническом справочнике](docs/MASTER_DEVELOPMENT_PROMPT.md) открывай раздел, относящийся к задаче.

Для композиции и адаптива открой [DESIGN.md](DESIGN.md), для фирменных цветов, логотипа и генерации изображений — [LENREMONT.md](LENREMONT.md). Точки входа и команды собраны в [DEVELOPMENT.md](DEVELOPMENT.md), готовые интеграции карты, прайса и квиза — в [HANDLER.md](HANDLER.md).

- Один статический Astro-лендинг внутри `#hop-landing`. Самостоятельная секция — отдельный Astro-компонент. Страница начинается первым экраном и заканчивается содержательной секцией без сайтной шапки и подвала.
- Классы получают префикс `lr-`, собственные селекторы ограничены корнем страницы или переносимого блока. SCSS находится в `src/styles`. Для поведения используй `data-*` и vanilla JS. Вход страницы — `src/scripts/landing.js`; квиз использует `public/scripts/lead-quiz.js` также на фронтенде WordPress.
- Медиа лежат в `public/media`. Формы и квизы соблюдают [контракт Lead Capture](docs/landing-kit/forms.md#lead-capture). Обработка демонстрационной формы разрешена только в DEV.
- Перед сдачей изменений запусти `npm run quality` и проверь сценарий по [карте маршрутов](.agents/workflows/landing.md). WordPress-экспорт, настройка публикации и учётные данные находятся за пределами шаблона.

[Запуск Pi и локальные настройки](docs/pi-harness.md)

Для независимого ревью, параллельных задач и разбора повторяющейся ошибки используй [роли и формат поручения](.agents/roles/team.md).

Для явной задачи переноса штатного квиза используй [контракт Gutenberg](docs/landing-kit/embedding.md). Общие стили квиза ограничивай `:is(#hop-landing, .lr-landing)`.
