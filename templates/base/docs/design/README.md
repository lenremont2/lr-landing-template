# Материалы дизайна

Храни здесь принятые референсы, ссылки на макеты и сравнения рендера с макетом. Для каждого укажи секцию, версию и ширину экрана. Например, пара снимков одного первого экрана при 390 px позволяет проверить кроп и положение CTA.

Выбранное направление и ссылки на материалы веди в [DESIGN.md](../../DESIGN.md), фирменные исходники и правила изображений бери из [LENREMONT.md](../../LENREMONT.md).
