# Шаблон задачи

Используй для поручения, которое передаётся другому исполнителю или продолжается в следующей сессии.

- **Цель** — какое действие посетителя или редактора должно заработать.
- **Вход** — маршрут, версия, бриф, референс или источник данных.
- **Границы** — ответственный, область изменений и зависимости от других задач.
- **Приёмка** — шаги проверки и ожидаемое наблюдение.
- **Результат** — изменённые файлы, фактическое наблюдение и открытый вопрос.
