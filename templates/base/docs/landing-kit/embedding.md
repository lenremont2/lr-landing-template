# Перенос в Gutenberg

## Квиз и модальное окно

`LeadCapture` с маркером `data-lr-component="lead-quiz-v1"` переносится одним блоком «Квиз с модалкой». Собери проект. Из репозитория Gutenberg выполни `node tools/astro-quiz.mjs --project <проект> --slug <новый-slug> --out <новый.zip>`. Адаптер читает один компонент из `dist/index.html` и создаёт пакет v4. Для нестандартной формы с собственным endpoint требуется отдельное сопоставление.

Работающий сценарий, значения для заявки и CSS переносятся вместе. Редактор меняет подписи, варианты, каналы и CTA. HTML On Page обслуживает финальную отправку через [контракт формы](forms.md). На этапе передачи проверь сохранение и повторное открытие черновика, затем сам диалог и поля на фронтенде. Офлайн-проверка ZIP подтверждает транспорт.

## Перенос из существующего проекта

Сравни `LeadCapture`, `LeadModal`, layout, стили и скрипты со свежим шаблоном. Перенеси версионированную обёртку, модуль `public/scripts/lead-quiz.js` и его подключение, сохрани локальные тексты и оформление. Убери повторную инициализацию тех же кнопок старым скриптом. Команда `update` обновляет справочник, а исходники и скиллы принадлежат проекту. Проверяй доступность блока на принимающем сайте перед импортом.

## Совместимость с окружением

Обычный Astro-лендинг ограничивает стили корнем `#hop-landing`. Переносимая часть также использует класс `.lr-landing` на корне блока. Стили редактора подключаются к холсту Gutenberg, модуль поведения — на фронтенде. Проверь дополнительные обёртки темы, заголовок страницы, ширину контейнера и работу с клавиатуры.

## Воспроизведение пилота

В созданном Astro-проекте положи `test/fixtures/lead-quiz-pilot.astro` из репозитория Landing Kit в `src/pages/pilot/[scenario].astro` и запусти сборку. Получатся маршруты `/pilot/default/`, `/pilot/custom/` и `/pilot/double/`. Для первых двух подготовь отдельные копии `dist`, скопировав соответствующий `pilot/<вариант>/index.html` также в корень `dist/index.html`. Сохрани каталог `pilot/` для браузерной проверки. Упакуй варианты с разными slug и запусти в репозитории Gutenberg следующую команду.

```sh
node tools/test-astro-quiz.mjs <путь-к-dist> <стандартный.zip> <изменённый.zip>
```

Проверка создаёт временный WordPress. Отчёт и снимки появятся в `dist/landing-quiz-*/` репозитория Gutenberg. Браузер перехватывает заявки локально.
