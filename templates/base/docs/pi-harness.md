# Pi в проекте Landing Kit

Из корня проекта запусти установленный Pi с настроенной моделью.

```sh
pi
```

На первом запуске подтверди доверие проекту, чтобы Pi обнаружил локальные скиллы в `.agents/skills/`. Затем дай обычную задачу, например «Добавь на лендинг секцию с этапами работы и проверь сборку». Pi получает [AGENTS.md](../AGENTS.md) при запуске и по нему находит [рабочий процесс](landing-workflow.md).

Общие правила проекта добавляй в [AGENTS.md](../AGENTS.md). Выбор скиллов и переходы меняй в [рабочем процессе](landing-workflow.md). Для повторяемого приёма создай `.agents/skills/<имя>/SKILL.md` с полями `name` и `description` и опиши, когда применять скилл, что прочитать, сделать и проверить.
