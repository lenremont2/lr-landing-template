# Как устроена страница

[Маршрут Astro](../../src/pages/index.astro) собирает секции в [общей оболочке](../../src/layouts/LandingLayout.astro). Сборка выдаёт статические HTML, CSS и JavaScript. Когда меняется состав секций, начни с маршрута. Для общего поведения проверь [точку входа JavaScript](../../src/scripts/landing.js).

Команды запуска и проверки собраны в [DEVELOPMENT.md](../../DEVELOPMENT.md). Границы между страницей и внешними системами описаны в [HANDLER.md](../../HANDLER.md). Принятый выбор, влияющий на несколько задач, зафиксируй в [решениях проекта](../decisions/README.md).
