# Как выбрать работу над лендингом

Начни с результата, запрошенного пользователем. Выбери одну строку для текущего шага и прочитай скилл по ссылке. Для ревью результатом будут наблюдения в отчёте. Утверждённый бриф, дизайн или референс используй как готовый вход.

| Задача                                                                                   | Ведущий скилл                                                             | Когда переходить дальше                                                                                                                    |
| ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| Проверить заявление, изучить аудиторию или составить бриф                                | [landing-research](../.agents/skills/landing-research/SKILL.md)           | Для каждой секции известны вопрос посетителя, проверенные факты, открытые вопросы и целевое действие.                                      |
| Выбрать направление новой страницы или запрошенного редизайна                            | [design-taste-frontend](../.agents/skills/design-taste-frontend/SKILL.md) | В дизайн-заметке есть решение по первому экрану, изображениям и CTA. Если задача заканчивается концепцией, передай заметку.                |
| Создать маршрут, заменить стартовый экран или перенести страницу по утверждённому макету | [landing-scaffold](../.agents/skills/landing-scaffold/SKILL.md)           | Секции собраны в порядке брифа. При переносе используй Project UI для сравнения результата с референсом.                                   |
| Добавить секцию в принятом дизайне, исправить адаптивность или провести визуальное ревью | [project-ui](../.agents/skills/project-ui/SKILL.md)                       | Для реализации проверь изменённое состояние. Для ревью дай наблюдения по рендеру, место и предлагаемое исправление, сохрани файлы проекта. |
| Исправить поле, маску или валидацию, включая телефон в квизе                             | [form-formatter](../.agents/skills/form-formatter/SKILL.md)               | Ввод, редактирование и очистка дают корректное значение в поле по контракту формы.                                                         |

Для полного лендинга по мере готовности входов переходи от брифа к композиции, реализации и сдаче. Специализированный скилл подключай, когда его результат нужен текущему шагу. Передавай ссылку на существующее решение. При паузе добавь в текущие материалы проверенный результат, открытый вопрос и следующий шаг.

## Сдача

- Для изменений кода запусти `npm run quality`. В собранном маршруте проверь один `#hop-landing`, порядок секций и цель основного действия. При ревью код остаётся в исходном состоянии.
- Проверь страницу на ширинах из брифа. Если ширины не заданы, выбери их по [правилам браузерной проверки](landing-kit/verification.md#браузерная-проверка) для локальной правки или приёмки всей страницы.
- Для изменённого интерактива пройди основной путь с клавиатуры. Для каждого проверенного состояния назови ширину и наблюдение. Повторно используй снимки и результаты того же состояния на той же версии. Технические ошибки исправь, визуальные советы оцени по брифу. Укажи недоступные проверки.

## Перенести квиз в Gutenberg

При явном запросе на перенос передай собранный Astro-проект и новый slug скиллу `lenremont-gutenberg`. Он готовит ZIP v4, проверяет пакет и импортирует его в режиме «Создать». После изменения текста и повторного открытия черновика сравни фронтенд с Astro. Редакторские правки принадлежат WordPress. Для повторной проверки используй новый slug. [Поддерживаемый компонент](landing-kit/embedding.md)
