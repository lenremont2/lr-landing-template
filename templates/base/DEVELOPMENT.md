# Разработка лендинга

Исходники проекта — статическая страница Astro. Работай из корня созданного лендинга. Версии инструментов и доступные команды указаны в [package.json](package.json). Для проекта, созданного с `--no-install`, сначала выполни `npm install`.

## Открой страницу

Запусти `npm run dev` и открой адрес из вывода Astro. Страницу собирает [index.astro](src/pages/index.astro), общую оболочку задаёт [LandingLayout](src/layouts/LandingLayout.astro).

## Найди место правки

Для секции открой ближайший [компонент](src/components/sections/) и принятое решение в [DESIGN.md](DESIGN.md). Стили секций подключаются через [landing.scss](src/styles/landing.scss).

Для поведения начни с [landing.js](src/scripts/landing.js). Если меняешь карту, прайс или квиз, сверь точку подключения с [HANDLER.md](HANDLER.md).

## Проверь собранный маршрут

Выполни `npm run quality` для диагностики Astro, форматирования и сборки. Запусти `npm run preview` и воспроизведи изменённый сценарий. Если посетитель нажимает кнопку или заполняет поле, пройди тот же путь с клавиатуры.

Для общих правил архитектуры, изоляции стилей, форм и приёмки открой нужную главу [технического справочника](docs/MASTER_DEVELOPMENT_PROMPT.md). Специфичные для этого проекта решения фиксируй здесь с путём к исходнику и способом проверки. Например, при добавлении второго маршрута укажи, откуда оба маршрута получают общие данные и как проверить различия.
