# Приёмка страницы

1. Выполни `npm run quality`, затем `npm run preview`. Открой изменённый маршрут.
2. На ширинах из брифа проверь цель первого экрана. С клавиатуры дойди до основной кнопки, нажми Enter и сверь результат с её подписью.
3. Если на странице есть модальное окно, открой его, пройди элементы с Tab, закрой с Escape и проверь возврат фокуса. Для формы проверь ошибку ввода и сохранение заполненных полей.
4. Запиши маршрут, ширины и фактический результат в задаче. Для главной страницы можно получить снимки и измерения командой `node scripts/inspect-home.mjs` после сборки.

Дополнительные сценарии для конкретной услуги добавляй рядом. [Полная приёмка](../docs/landing-kit/verification.md)
