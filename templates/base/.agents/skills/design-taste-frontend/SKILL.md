# Taste для лендинга

Прочитай бриф и определи основное действие посетителя. Посмотри фирменные материалы, доступные изображения и существующие компоненты. Если макет уже принят, передай его в [project-ui](../project-ui/SKILL.md) для реализации по референсу.

## Выбери композицию

Определи, что посетитель заметит первым, как заголовок связан с изображением и куда ведёт CTA. Продумай иерархию текста и ритм секций. Соседним секциям подбери композицию по их содержанию. При определённом брифе предложи одно направление и обоснуй его. Сравни варианты, если бриф действительно допускает разные решения.

Для подбора используй [draw.mjs](scripts/draw.mjs). Передай роли секций из брифа, исключив `footer`. Выбор и причины запиши в [DESIGN.md](../../../DESIGN.md) или дизайн-заметке, указанной в задаче.

## Подбери изображения

Начни с локальных материалов. Для поиска доступен [assets.mjs](scripts/assets.mjs). Проверь происхождение и разрешённое использование, сохрани выбранные файлы в `public/media`. Стоковые и сгенерированные изображения обозначай как иллюстрации.

Посмотри на каждый кадр рядом с текстом секции. Какую деталь услуги он помогает понять? Если ответ неясен, пересмотри кадр или его место. Соблюдай факты и ограничения бренда.

Если заказана концепция, передай заметку с первым экраном, порядком секций, изображениями и основным действием. Для реализации используй Project UI. По [условиям сдачи](../../workflows/landing.md) проверь композицию, читаемость и уместность визуала на снимках, а фокус и переход по CTA в браузере. После исправления повтори затронутую проверку.

## Инструменты Taste

При открытом брифе можно сравнить варианты командой из корня проекта. Для сохранения выбора повтори запуск `draw.mjs` с `--direction <id>` вместо `--options 3`, чтобы сохранить выбранный вариант в `.taste-skill/`.

```sh
node .agents/skills/design-taste-frontend/scripts/draw.mjs --sector other --brief "Ремонт телевизоров ЛЕНРЕМОНТ" --sections hero,list,pricing,how-it-works,faq,cta --options 3
```

После успешной сборки запусти [inspect.mjs](scripts/inspect.mjs) из `dist/`, чтобы локальные пути начинались от корня сборки. Нужен установленный Chrome, Edge или Chromium.

```powershell
Push-Location dist
node ../.agents/skills/design-taste-frontend/scripts/inspect.mjs index.html --widths 360,390,768,1280,1440 --out ../.taste-skill/final
Pop-Location
```

Сверяй замечания инспектора с задачей и снимками. Для композиции, шрифтов и цвета есть [layout](references/layout.md), [type](references/type.md) и [colour](references/colour.md). Для работы над содержанием и визуальными материалами используй [copy](references/copy.md) и [imagery](references/imagery.md). Если задача требует движения, смотри [motion](references/motion.md). Для разбора снимков используй [critique](references/critique.md). Если браузер недоступен, запиши, какую проверку не удалось сделать.
