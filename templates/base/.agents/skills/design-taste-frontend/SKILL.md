# Taste для лендинга

Этот профиль использует локальные инструменты Taste для выбора направления и браузерной проверки. Пакет содержит исходные скрипты и лицензию Taste.

1. Прочитай бриф и зафиксируй основное действие. Найди принятые элементы бренда, существующие компоненты и реальные доступные материалы. Для точной реализации референса следуй референсу. Для существующего утверждённого дизайна используй его язык через [project-ui](../project-ui/SKILL.md).
2. При определённом брифе предложи одно направление и обоснуй его. Если бриф допускает существенно разные композиции, сравни несколько вариантов. Для подбора доступен [draw.mjs](scripts/draw.mjs). Передай роли секций из брифа явно, без роли `footer`. Оцени, как композиция показывает содержание и ведёт к действию. Зафиксируй выбор и причины в существующих дизайн-заметках или `docs/design.md`.
3. Дай странице одну выразительную композицию первого экрана, ясную иерархию текста, согласованный ритм секций и подходящее изображение или содержательную визуализацию по теме. Сделай соседние секции различимыми по композиции. Сохрани ограничения бренда и фактов. Изображения бери из проекта либо используй разрешённые материалы с указанным происхождением. Сгенерированное или стоковое изображение описывай как иллюстрацию. Для найденных изображений есть [assets.mjs](scripts/assets.mjs). Сохраняй выбранные медиа в `public/media`. Проверь каждое фото рядом с текстом блока по правилам project-ui. Если снимок ничего не объясняет в этом месте, пересмотри его назначение.
4. Перед реализацией зафиксируй, как выбранное направление влияет на первый экран, порядок или ритм секций и использование изображений. Если заказана концепция, передай дизайн-заметку. Если заказана реализация, используй project-ui и проверь снимки по [условиям сдачи](../../../docs/landing-workflow.md). По снимкам оцени ясность заголовка и действия, уместность визуала, композицию и читаемость. Исправь заметные проблемы и повтори проверку затронутых состояний. Клавиатурный фокус и переход по CTA проверь в браузере.

При открытом брифе можно сравнить варианты командой из корня проекта. Для сохранения выбора повтори запуск `draw.mjs` с `--direction <id>` вместо `--options 3`, чтобы сохранить выбранный вариант в `.taste-skill/`.

```sh
node .agents/skills/design-taste-frontend/scripts/draw.mjs --sector other --brief "Ремонт телевизоров ЛЕНРЕМОНТ" --sections hero,list,pricing,how-it-works,faq,cta --options 3
```

После успешной сборки запусти [inspect.mjs](scripts/inspect.mjs) из `dist/`, чтобы локальные пути начинались от корня сборки. Нужен установленный Chrome, Edge или Chromium.

```powershell
Push-Location dist
node ../.agents/skills/design-taste-frontend/scripts/inspect.mjs index.html --widths 360,390,768,1280,1440 --out ../.taste-skill/final
Pop-Location
```

Сверяй замечания инспектора с задачей и снимками. Для композиции, шрифтов и цвета есть [layout](references/layout.md), [type](references/type.md) и [colour](references/colour.md). Для работы над содержанием и визуальными материалами используй [copy](references/copy.md) и [imagery](references/imagery.md). Если задача требует движения, смотри [motion](references/motion.md). Для разбора снимков используй [critique](references/critique.md). Если браузер недоступен, запиши, какую проверку не удалось сделать.
