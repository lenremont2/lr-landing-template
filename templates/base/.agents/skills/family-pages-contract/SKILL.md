# Измени семейство страниц

Найди родительскую страницу, дочерние URL, общие компоненты и источники различий. Для точечной правки возьми текущие исходники, правила проекта и описание изменения. Уточни только пробелы, от которых зависит результат.

## Выдели общее и индивидуальное

Оставь общую разметку и поведение в компонентах. Отличия услуги, бренда или города передай через данные и параметры. Для каждого отличия нужен подтверждённый факт. Если пока известно только название, отметь недостающие сведения. Сохрани принятые URL и способ сборки. Исследование спроса выполняй по отдельному запросу.

Для нового семейства или изменения структуры опиши родителя, типы страниц, источники данных, общие блоки, переопределения и применимые правила индексации. Сошлись на данные в существующем контракте проекта. Если формата ещё нет, используй `docs/family-pages.contract.md`. При локальной правке достаточно обновить затронутые сведения там, где они уже определены.

## Проверь образец перед тиражированием

Собери родителя и по одному образцу каждого типа. Для новых и перемещённых URL обнови внутренние ссылки, существующие хлебные крошки и sitemap по правилам проекта. При изменении маршрута или содержания сверь title, description и canonical. Для ссылки canonical используй назначение страницы и принятое SEO-решение. Родство страниц само по себе его не определяет.

## Проверь все затронутые URL

Запусти сборку. После правки общего компонента проверь доступными автоматическими средствами маршруты всех его потребителей, отсутствие коллизий, ссылки и соответствие данных контракту. Сохрани правила изоляции, форм и медиа.

В браузере открой образец каждого изменённого типа и страницы с особыми переопределениями. Обойди всё семейство, если этого требует задача или выборка пропускает существенные отличия. В отчёте перечисли изменённые URL, браузерную выборку, непроверенные части и страницы с конфликтом маршрутов или нехваткой данных.
