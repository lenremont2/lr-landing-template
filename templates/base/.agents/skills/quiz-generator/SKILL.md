# Измени путь посетителя в квизе

Прочитай существующий компонент и выясни, кто читает его результат. Возьми из задачи цель, вопросы, допустимые ответы, зависимости и правила расчёта. Для заявки сверь контактный шаг и ожидаемые поля с [контрактом формы](../../../docs/landing-kit/forms.md#lead-capture). Если правила ветвления, расчёта или подключения неполны, укажи пробел и выполни независимую часть.

## Опиши переход

Для каждого затронутого вопроса зафиксируй его ID, варианты, условие применимости, следующий шаг и ключ итогового ответа. Используй принятый формат проекта. Если его нет, сохрани описание в `docs/quiz.contract.md`. Определи начальный шаг, когда доступно «Далее», куда ведёт «Назад» и чем завершается сценарий. [Контракт квиза](../../../docs/landing-kit/forms.md#quiz)

Переиспользуй компоненты и механизм отправки проекта. Простой последовательности достаточно обычных переходов. Сохрани согласованные вопросы. Добавляй ветвление и расчёт цены, когда они нужны по задаче. Показывай прогресс по известному пути и укажи ограничения оценки цены.

## Отличай скрытый шаг от устаревшего ответа

При возврате на предыдущий шаг сохрани применимый ответ. При смене услуги пересчитай путь и исключи ответ прежней ветки из результата и полей заявки. Переход к следующему экрану сам по себе оставляет ответ применимым.

Свяжи устойчивые ID с итоговыми данными. Для HTML-формы используй реальные поля с `name` и `value`. У `lead-quiz-v1` при редактировании подписи сохрани техническое `value`.

## Пройди путь как посетитель

1. Для нового квиза пройди каждую заданную ветвь. Для правки пройди изменённый переход, зависимые шаги и основной путь. Проверь доступность обязательных шагов, отсутствие тупиков и непредусмотренных циклов.
2. Проверь подписи, группы вариантов, перенос фокуса, клавиатуру и мобильную прокрутку. Валидируй текущий шаг при движении вперёд и весь применимый путь при завершении. Скрытые шаги пропускают фокус. Возврат доступен без заполнения нового ответа.
3. Сверь кнопки и обработчики. «Далее», «Назад» и Enter на промежуточном шаге оставляют заявку неотправленной. Для правки самого контактного поля подключи [form-formatter](../form-formatter/SKILL.md).
4. Посмотри итоговые поля локально, без отправки. Каждый применимый ответ и контакт представлены один раз. Для `lead-quiz-v1` вернись из выбора канала и формы, смени ответ и снова открой квиз. Сверь `quiz_answer` и `contact_method` с последним выбором.

Верни пример итоговых данных без персональных сведений. Если есть расчёт, сверь его с предоставленными правилами. Перечисли пути, пройденные в браузере, и оставшиеся пробелы.
