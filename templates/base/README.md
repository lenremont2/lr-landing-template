# Структура лендинга

```text
.
├── AGENTS.md                     Правила проекта и выбор маршрута
├── CLAUDE.md                     Подключение общих правил в Claude Code
├── DESIGN.md                     Дизайн этой страницы
├── DEVELOPMENT.md                Локальная разработка и проверка
├── LENREMONT.md                  Бренд, логотип и изображения
├── HANDLER.md                    Карта, прайс и квиз
├── .agents/
│   ├── skills/                   Предметные скиллы
│   ├── workflows/               Маршруты разработки и цикл улучшения
│   ├── roles/                   Ответственность и передача задач
│   └── evals/                   Контрольные задания для агента
├── .claude/agents/              Профиль проверяющего для Claude Code
├── .cursor/rules/               Правило ревью для Cursor
├── .codex/agents/               Профиль проверяющего для Codex
├── docs/
│   ├── product/                 Бриф, аудитория, источники и цель
│   ├── architecture/            Устройство страницы и интеграции
│   ├── design/                  Материалы макета и визуальной приёмки
│   ├── decisions/               Принятые решения проекта
│   ├── tasks/                   Постановки задач и результаты
│   └── landing-kit/             Технический справочник комплекта
├── src/                         Исходники Astro
├── public/                      Медиа и статические ресурсы
├── tests/                       Приёмочные сценарии страницы
└── scripts/                     Исполняемые инструменты проекта
```

Начни с [правил проекта](AGENTS.md) и [брифа](docs/product/brief.md). Для конкретной задачи выбери [маршрут](.agents/workflows/landing.md). Чтобы передать работу другому исполнителю, используй [контракт роли](.agents/roles/team.md). После изменения инструкции проверь её на [контрольном задании](.agents/evals/routing.md).
